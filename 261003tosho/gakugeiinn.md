# 🌿 学芸員資格の取りやすい大学・大学院ガイド

> 🌱 個別の大学の開講状況、単位数、履修条件は年度ごとに変わります。最終的には各大学の公式サイト・履修要覧で確認してください。

## 🟢 1. 学芸員資格の基本

- 根拠法は博物館法です。
- 取得ルートは主に3つあります。
  1. **大学で所定の科目を修得して卒業する**(最も一般的)
  2. **文部科学省の学芸員資格認定(試験認定・審査認定)に合格する**
  3. **学芸員補として実務経験を積み、認定を受ける**(現実的には少数派)
- ルート1では、**学士の学位**と**博物館に関する科目(約19単位前後)**が必要です。
- 主な科目は、博物館概論、博物館経営論、博物館資料論、博物館資料保存論、博物館展示論、博物館教育論、博物館情報・メディア論、博物館実習などです。
- 資格を取っても、学芸員として就職できるとは限りません。採用は少なく、実際には修士以上や専門分野の研究実績を求められることが多いです。

## 🟢 2. 「取りやすい大学」を見分けるポイント

| チェック項目 | 見るべき点 |
|---|---|
| 課程の設置 | 学芸員課程があるか、どの学部・学科で履修できるか |
| 履修制限 | 人数制限や選抜がないか、学部を問わず履修できるか |
| 履修開始時期 | 1年次から取れるか(3年次からだと厳しくなりやすい) |
| 館園実習 | 実習先を大学が手配してくれるか、学内博物館で実習できるか |
| 追加費用 | 課程登録料、実習費、交通費・宿泊費 |
| 時間割 | 卒業単位に含まれるか、別枠でどれだけ負担になるか |

**最大のハードルは「博物館実習」です。** 館園実習の受け入れ先を自分で探す大学もあります。申込時期が早く、事前指導や出席の条件も厳しいため、**実習のサポート体制が手厚い大学ほど取りやすい**と言えます。

## 🟢 3. 取りやすい傾向のある大学の例

以下は「学芸員課程が充実している、または履修しやすいとされる」代表例です。入学前に最新情報を確認してください。

### 🍀 関東

- **國學院大學**:博物館学の教育・研究で有名で、学内に博物館があります。
- **明治大学**:大学博物館があり、課程も充実しています。
- **大正大学、駒澤大学、東洋大学、日本大学、立教大学**など:文学部系を中心に課程があります。

### 🍀 関西

- **同志社大学、立命館大学、龍谷大学、佛教大学、関西大学**など:歴史・文化系に強く、大学付属の博物館・資料館を持つ大学も多くあります。

### 🍀 北海道

- **北海道大学、北海学園大学、酪農学園大学**などに課程があるとされています。開講状況は必ず公式サイトで確認してください。

### 🍀 芸術系・専門分野

- **東京藝術大学、武蔵野美術大学、京都芸術大学、多摩美術大学**など:美術館学芸員志望者向けです。
- 美術・考古・歴史・民俗・自然科学など、**志望する館の分野の専門学部**を選ぶのが就職面では有利です。

## 🟢 4. 大学院での取得について

- **学芸員課程を置く大学院は多くありません。** 専門研究を深める場として使うのが一般的です。
- すでに学士を持っている場合は、次の方法が現実的です。
  - **科目等履修生**として、大学の博物館学関連科目を履修する
  - **通信教育課程**に入り、科目を履修する
- 大学院在学中に取得する場合は、大学院に課程があるか、学部の課程を科目等履修できるかを確認してください。
- 学芸員の採用では、**修士号(専門分野)が事実上の条件**になっている館が多いです。

## 🟢 5. 社会人・他学部卒向けの選択肢(通信教育)

資格だけ追加したい場合は、通信教育課程が選択肢になります。

- 玉川大学通信教育部
- 佛教大学
- 武蔵野美術大学通信教育課程
- 京都芸術大学通信教育部
- 法政大学通信教育部
- 日本大学通信教育部
- 明星大学通信教育部

※設置状況、学費、スクーリングや実習の条件は大学ごとに異なります。

## 🟢 6. 学芸員資格認定(試験認定)

- 大学に通わずに資格を得る方法です。
- 筆記試験(年1回)に合格し、さらに実務経験等の条件を満たす必要があります。
- 試験科目が多く、難易度は高めです。**「簡単に取れる」ルートではありません。**

## 🟢 7. 結論:何を基準に選ぶか

1. **目的が資格取得のみなら**:学芸員課程があり、履修制限がなく、実習の手配が手厚い大学を選ぶ
2. **学芸員として就職したいなら**:志望分野の専門学部に進み、**大学院(修士)まで見据える**
3. **すでに社会人・他学部卒なら**:通信教育課程か科目等履修を検討する
4. **どの場合でも**:履修開始時期と館園実習のスケジュールを早めに確認する
